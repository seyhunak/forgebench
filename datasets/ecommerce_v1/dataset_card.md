# Dataset card: ecommerce_v1

- **Name:** ecommerce_v1
- **Version:** 1.0.0
- **Task:** e-commerce order reconciliation and exception triage
- **Created:** 2026-10-15 (fully synthetic; no customer data)
- **Total cases:** 180
- **License:** Apache-2.0 (synthetic data generated by this repository)

## What is in it

Each case shows one marketplace order next to its ERP (Enterprise Resource Planning) record and asks:
do these match, and if not, what kind of exception is it? Ground truth is produced by deterministic rules,
never by a model.

| Family | Ground truth |
| --- | --- |
| matched | amounts, dates and references agree |
| amount_mismatch | order amount differs from ERP amount |
| date_mismatch | dates differ, amounts agree |
| reference_mismatch | order reference differs from ERP reference |
| duplicate | one side shows more occurrences than the other |
| ambiguous | conflicting weak signals; must be escalated to a human |
