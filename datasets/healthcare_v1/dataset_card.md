# Dataset card: healthcare_v1

- **Name:** healthcare_v1
- **Version:** 1.0.0
- **Task:** medical claims reconciliation and exception triage
- **Created:** 2026-10-15 (fully synthetic; no patient data)
- **Total cases:** 180
- **License:** Apache-2.0 (synthetic data generated by this repository)

## What is in it

Each case shows one insurance claim next to its EOB (Explanation of Benefits) counterpart and asks:
do these match, and if not, what kind of exception is it? Ground truth is produced by deterministic rules,
never by a model.

| Family | Ground truth |
| --- | --- |
| matched | amounts, dates and references agree |
| amount_mismatch | claim amount differs from EOB amount |
| date_mismatch | dates differ, amounts agree |
| reference_mismatch | claim reference differs from EOB reference |
| duplicate | one side shows more occurrences than the other |
| ambiguous | conflicting weak signals; must be escalated to a human |
